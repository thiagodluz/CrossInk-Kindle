# PW1 0.3.7 — continuous-session checks

Date: 2026-10-15. Physical validation of 0.3.7 is pending. The separately
recorded 0.3.6 normal lifecycle tests passed and remain historical evidence.

## Behavior and automated evidence

- `python3 scripts/kindle/check-host.py`: complete host suite passed, including
  backend/display/power/session/descriptor, supervisor, 50 launcher cases,
  TXT preview and native storage/worker checks.
- The real RenderWorker supplies the render pulse in new launcher fixtures.
  Controlled cases cover healthy idle reading, input-only stall, render-only
  stall, SIGSTOP of the entire reader, no startup pulses, supervisor SIGKILL
  with runner parent-death cleanup, and runner SIGKILL with token recovery.
  Existing power/corner grace, intermediary-shell, reopen, stale-token,
  journal/race and failed-restoration tests still pass.
- `check-supervisor.py` exercises the production native supervisor and pipe on
  host and static ARM under qemu-arm-static with the legacy glibc 2.12.2
  sysroot. Healthy, missing/stale channels and missing startup pulses pass.
  Descriptor validation, pulse throttling, lost-reader pipe failure and ignored
  inherited SIGCHLD are checked. The SIGCHLD reset/check was added after the
  full host suite and rerun separately on host and ARM.
- `check-power.py` passes on host and ARM, including exact activity-command
  arguments, 30-second rate limiting, command failure/deadline and child reaping.
  No activity calls occur without an explicit input notification.
- ARM TXT preview pixels match host output. Static ARM softfp/minimum Linux
  2.6.31 ELF and pre-strip NSS audits pass. Source formatting/syntax/whitespace
  checks pass. SDK stays at `699370183fa3a0e33c9cb83a36f701bbb6022095`.

The timeouts in launcher/supervisor fixtures are shortened to test deadlines
without waiting minutes. These are controlled tests, not a 20-minute physical
reading test or a measurement of PW1 battery/RAM cost. The host integration
tests cover actual worker stalls and session recovery; the ARM supervisor
fixtures cover the native monitor/pipe with a controlled shell sender.

## Physical retest

Install 0.3.7 by merging directories and preserving data. The updated sample TXT
has a new content hash and may restart its saved position; other books are
unchanged. Close the old app before installing.

Read for 15–20 minutes with regular page turns: there must be no forced exit at
five/six minutes. Then test power sleep → wake → KUAL reopen → saved page,
normal Exit, corner hold and bar/sleep-image appearance. Finally leave a session
untouched, record the time until stock inactivity sleep, and verify reopening.
Collect launcher.log, ui.log and ui.previous.log. No deliberate physical crash
is required from the user for this test.

Expected: `supervisor=started` in launcher.log; real touches may log
`user_activity=reset exit=0`. Timer renewal is touch-driven, at most every
30 seconds, and never heartbeat-driven. Failure is logged/throttled and leaves
stock sleep possible. No preventScreenSaver setting is changed.

In-memory suspend/resume and EPUB remain unimplemented. The diagnostic retains
its 90-second application limit and 120-second watchdog. The UI supervisor uses
60-second startup, 15-second input, 30-second render and 10-second runner-cleanup
deadlines, followed when needed by bounded session-token recovery.
